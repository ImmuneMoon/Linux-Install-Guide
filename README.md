## 📖 Overview
The **Linux Install Guide** walks first-time users through moving a PC to Linux, from picking a version to the first updates. It's a good fit for PCs that can't run Windows 11, and it helps keep older hardware out of the bin.

The guide is built around one idea: you can run Linux from a USB drive and test everything before you change anything on your PC. It covers Linux Mint, Zorin OS, and Ubuntu, and it covers replacing Windows or installing alongside it.

## 🗂 Contents of the Guide
The main document (`Guide.md`) is divided into these sections:
1. **How a Linux Install Actually Works** - The ISO, the USB drive, and the live session.
2. **Before You Start** - Backups, your BitLocker key, and checking your apps.
3. **Step 1: Choose Your Linux** - A comparison of Linux Mint, Zorin OS, and Ubuntu.
4. **Step 2: Download and Check the ISO** - Confirming your download is intact.
5. **Step 3: Make the USB Drive** - Walkthroughs for balenaEtcher and Rufus.
6. **Step 4: Start From the USB Drive** - Boot menu keys and Secure Boot.
7. **Step 5: Try It Before You Install** - What to test while it's still safe to walk away.
8. **Step 6: Install It** - Replacing Windows or installing alongside it, with the Linux Mint installer steps.
9. **Step 7: After the Install** - Updates, drivers, and system snapshots.
10. **Where to Get Help** - Forums and free community repair groups.
11. **If Something Goes Wrong** - Common problems and what to do.
12. **Fixes That Don't Help** - Advice to skip.
13. **Quick Checklist** - A short summary to work through.

## ⚠️ Important Disclaimer
Installing Linux can permanently erase your drive, and installing alongside Windows changes its partitions. Back up anything you can't afford to lose first, and check the drive before you click **Install**. Versions, menu names, and support dates change, so confirm them on each project's site.

## 🚀 How to Use
Download the PDF above, or open `Guide.md` in any Markdown viewer, text editor, or code editor (such as VS Code, Notepad++, or Obsidian). Start with **Before You Start** and work through the steps in order. You can stop after **Step 5** without having changed anything on your PC.

This guide works alongside two others:
* [Windows 10 Community Support Guide](https://github.com/ImmuneMoon/Windows-10-Community-Support-Guide) - Your options if you're leaving, or staying on, Windows 10.
* [Windows Install Guide](https://github.com/ImmuneMoon/Windows-Install-Guide) - Making a Windows USB drive, if you'd rather stay on Windows.
